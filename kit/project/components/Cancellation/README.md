# Cancellation

When money comes back if plans change, as dates on a line.

## When to use

Before booking a stay.

## What you provide

```ts
Gratifi.Cancellation(props: { steps?: {tone, t, s}[] })
```

## Rules

- Dates, not policy wording.

## Example

Wrap the app in `className="gr"`, then:

```jsx
const { Cancellation } = window.Gratifi

<Cancellation />
```

`Gratifi.demos.Cancellation()` renders every state on this card.
