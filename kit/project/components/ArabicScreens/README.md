# ArabicScreens

Right-to-left check: the flight answer, calendar, seat map and payment in Arabic for the UAE.

## When to use

Use it to check any new block in right-to-left before release. The Arabic copy is a draft for layout.

## Example

Wrap the app in `className="gr"`, then:

```jsx
const { ArabicScreens } = window.Gratifi

<ArabicScreens />
```

`Gratifi.demos.ArabicScreens()` renders every state on this card.
