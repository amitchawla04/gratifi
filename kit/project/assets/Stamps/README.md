# Stamps

Perforated postage stamps, one per reward category: plane, hotel, dining, gift, ticket, car, bag, balloon, music, takeaway. Used by the Stamp component (`Gratifi.ART.stampPlane` and so on) for collected rewards and category tiles.

- Each stamp carries its own white paper and perforation; show it on `ground`, `screen` or `card` with `shadow-paper`.
- Tilt a stamp by 1 to 4 degrees. Never more than four stamps in a row.
