# First 25 brands

These 25 brands each did something public in the last 12 months that shows they need exactly this: a new program with thin rewards, a relaunch, or a boss saying repeat customers are the priority.

**Best three to call first:** Akasa Air, Vi and Cenomi. All three just launched a program and have almost no rewards to offer yet. That is the gap our rewards catalogue fills.

How to read this: the brand name links to the source page. None of these brands has said it is shopping for a vendor; these are signs the timing is right. Some earnings-call quotes come from sites that summarise calls, so check the original transcript before quoting a number to the brand.
